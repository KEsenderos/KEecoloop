KEecoloop は、音声ファイルの好きな区間をくり返し再生して、外国語を聞き取る練習をするためのアプリです。使い方は次のとおりです。

1. 音声を選ぶ

右上の ⏏ をタップして、iPhone の「ファイル」アプリから音声ファイルを選びます。
Google ドライブにある音声は、先に iPhone の「このiPhone内」へ保存しておきます。
選ぶと、0〜5秒の区間が設定されます。

2. 区間を決める

「開始」と「終了」の数字は、4桁（分:秒）それぞれの上にある ▲ と下にある ▼ で変えます。
たとえば秒の一の位の ▲ を押すと1秒、十の位だと10秒、分の位だと1分や10分、進みます。
開始は、終了より前になるように止まります。

3. 再生する

大きな ▶ を押すと、決めた区間をくり返し再生します。押すと ⏸ になり、一時停止できます。
■ は停止です。位置が開始地点に戻ります。



5. 速さを変える

一番下の「1.2」「1.1」「1.0」「0.9」「0.8」は倍速のボタンです。押すとすぐ、その速さで区間のくり返し再生が始まります。
声の高さは変わりません。
音声を選び直すと、1.0 に戻ります。

その他

画面を消しても、ロック画面やイヤホンのボタンから、再生と一時停止、区間移動ができます。
画面の一番下に出る「v1.7.0」は、アプリの版の表示です。
新しい版が出たときは、タイトル行の下に帯が出ます。タップすると更新されます。
